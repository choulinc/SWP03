# 辦點事 · To-Do List

[線上使用](https://choulinc.github.io/SWP03/) · 純 HTML、CSS、JavaScript，無需帳號或後端。待辦資料存在目前瀏覽器的 LocalStorage。

## 這次新增的 20 個功能

1. **截止日**：為事項指定日期，並在清單中顯示。
2. **優先順序**：設定高、中、低優先。
3. **分類**：用自訂文字將事項分類。
4. **備註**：為事項記下細節。
5. **子任務**：把大事拆成小步驟，逐項勾選。
6. **重複事項**：每天、每週或每月重複；完成後自動建立下一次。
7. **置頂**：讓重要事項排在最前面。
8. **複製事項**：快速建立相似待辦。
9. **封存與還原**：把暫時不需要的事項移出清單，之後可還原。
10. **搜尋**：搜尋事項名稱、備註、分類與子任務。
11. **逾期篩選**：集中查看已超過截止日而未完成的事項。
12. **優先順序篩選**：只看指定優先等級。
13. **分類篩選**：只看指定分類。
14. **排序**：依新增時間、截止日、優先順序或名稱排列。
15. **批次處理**：選取多項後一起標記完成或刪除。
16. **刪除復原**：刪除後可在提示中復原。
17. **匯出備份**：下載包含所有事項的 JSON 檔。
18. **匯入備份**：從 JSON 檔合併事項，略過相同 ID。
19. **深色模式**：切換外觀並記住偏好。
20. **鍵盤捷徑**：按 `N` 聚焦新增欄，按 `/` 聚焦搜尋欄；`Escape` 關閉選取模式。

原有的新增、編輯、完成、刪除、狀態篩選、清除已完成及進度顯示仍可使用。編輯事項名稱可直接點擊事項，詳細視窗也可設定截止日、優先順序、分類、備註、子任務及重複規則。

## 本機使用

在專案目錄執行 `python3 -m http.server 8000`，再開啟 `http://localhost:8000`。

## 部署

推送到 `main` 後，GitHub Actions 會部署到 GitHub Pages。工作流程位於 `.github/workflows/deploy.yml`。

資料只保存在目前瀏覽器與網站來源，不會跨裝置同步。建議定期使用「匯出備份」。
